# Support

We’re happy to help with setup, bug reports, feature questions, and development guidance.

## Before you ask

- Search existing issues
- Check the README
- Review the troubleshooting guidance in the docs

## How to ask for help

- For bugs: open a GitHub issue using the bug report template
- For feature requests: use the feature request template
- For general questions: open a GitHub discussion or ask in the project’s public support channel

## Response expectations

Support is best-effort and depends on maintainer availability. We’ll try to respond promptly to well-scoped questions and reproducible bug reports.

## Security issues

Please do not open a public issue for security vulnerabilities. Follow the process in [SECURITY.md](./SECURITY.md).
