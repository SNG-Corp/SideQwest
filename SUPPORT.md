# Support

This repository is an MVP and does not provide production service support or an SLA.

- **Bug reports and feature requests:** use the repository's [issue tracker](https://github.com/SNG-Corp/SideQwest/issues) and choose an appropriate template.
- **General project questions:** use [GitHub Discussions](https://github.com/SNG-Corp/SideQwest/discussions) when available.
- **Security vulnerabilities:** do not post publicly; see [SECURITY.md](SECURITY.md).

Please avoid posting phone numbers, identity documents, precise location, payment references, credentials, or other private information. Support is best-effort and maintainer availability may vary.
