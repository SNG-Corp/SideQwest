# Roadmap

This roadmap reflects the next stages needed to turn the current MVP into a stable, maintainable, sponsor-friendly product.

## Near-term (0–3 months)

- stabilize the production deployment flow
- improve onboarding and environment validation
- harden CI checks and required branch protections
- finalize contribution and security policies
- publish first public release notes and changelog entries

## Medium-term (3–6 months)

- production deployment for Postgres, Redis, and object storage
- add observability dashboards and alerting
- complete compliance and audit review for KYC and payment workflows
- improve retries, failed payment recovery, and idempotency reporting
- expand end-to-end test coverage for money-path scenarios

## Longer-term

- multi-market expansion and localized pricing logic
- additional payment rails and operational tooling
- on-call maintenance model and release cadences
- public case studies and sponsorship updates

## Request for community input

If you are contributing to or sponsoring this project, the most valuable improvements are:

- security hardening
- production automation
- better monitoring and incident response
- documentation quality
- contributor onboarding
