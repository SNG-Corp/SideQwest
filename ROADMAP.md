# Roadmap

This roadmap is a planning aid, not a promise of delivery dates or production availability. Track progress through repository issues and pull requests.

## Before any public store release or live funds

- Complete privacy/legal review, publish accurate privacy and terms notices, and implement account deletion and retention controls.
- Resolve location consent and idle-presence behavior; validate data flows and disclosures.
- Test real payment, issuer, SMS, and object-storage provider sandboxes and failure/reconciliation paths.
- Produce and test signed iOS and Android release artifacts on devices.
- Establish production deployment, monitoring, incident response, backups, restore drills, and key rotation.
- Stabilize CI and configure protected-branch required checks.

## Community and maintenance

- Keep setup and architecture documentation synchronized with code.
- Triage security and dependency findings.
- Publish release notes only for actual tagged releases.
- Invite additional maintainers/reviewers as project capacity permits.
